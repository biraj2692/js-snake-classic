# 🐍 Snake Game

A simple and modern Snake game built using **HTML**, **CSS**, and **JavaScript**.  
Features include smooth movement, random food spawning, score tracking, high-score saving (localStorage), timer, and clean start/game-over modals.

---

## 🚀 Features
- Grid-based snake movement  
- Food generation & snake growth  
- Score + persistent high score  
- Live survival timer  
- Start & Game Over screens  
- Customizable block size and colors  

---

## 📂 Project Structure
📦 snake-game
┣ 📜 index.html
┣ 📜 style.css
┗ 📜 script.js

---

## 🕹️ Controls
Use the **Arrow Keys** to move: ⬆ ⬇ ⬅ ➡  
Eat food → grow longer  
Avoid walls → or game over  
Try to beat your **High Score**!
